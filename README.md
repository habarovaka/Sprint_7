# Проект автоматизации тестирования API Яндекс.Самокат
Этот проект содержит автотесты для проверки ключевых эндпоинтов учебного сервиса Яндекс.Самокат (создание и логин курьера, создание заказов и получение их списка).

## Стек технологий
* Python 3
* Pytest (тестовый фреймворк)
* Requests (HTTP-клиент)
* Allure (отчетность)

## Подготовка и запуск
Установите зависимости:
pip install -r requirements.txt
